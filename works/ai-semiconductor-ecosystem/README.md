# AI 半导体产业链生态图

本地静态可视化应用，无需安装依赖。

入口：

- `index.html`

当前版本：

- 27 个 AI 半导体产业链环节
- 每个环节 5 个关键玩家
- 107 个唯一公司/机构节点
- 机箱/芯片式产业链界面
- 更接近真实 AI 加速器封装的芯片/板卡俯视图：GPU、HBM、硅中介层、ABF 基板、BGA、CPU、NIC、光模块、电源、retimer、冷板、晶圆、EDA、前道设备等元件可点击联动产业链环节
- 元件之间用连线展示设计、晶圆制造、HBM PHY、2.5D 封装、板级互连、电源、散热和光互连关系
- 环节模块可从主机箱中“拆出”
- 切换环节时有模块沿信号线飞出的爆炸视图动画
- 每个环节可继续向下一层展开为器件、工艺、材料或系统模块
- 选中下一层模块后继续展开第三层：材料、设备、工艺、供应商
- 第三层供应商标签可联动公司详情和地图
- 公司总部地图点位
- 公司详情卡片：地址、CEO、创立信息、创始/来源、生态角色、来源链接
- 搜索：公司、环节、城市
- 地图模式：当前环节 / 全产业链
- 地球/地图上叠加创始人籍贯网络与投资网络
- 网络图支持籍贯网络/投资网络切换、地理/Circle/分层布局切换和节点拖动整理

数据说明：

- 当前是 `v0.1 seed`，用于快速探索和交互原型。
- 地图坐标以总部城市或公开园区位置为主，不等同于严格工商注册地址。
- `confidence` 字段标记数据状态；后续正式研究应逐家公司用年报、交易所公告、公司官网和注册文件核验。
